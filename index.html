Umbra

Open source · Android agent · Active development

An autonomous agent designed to live on an Android phone. Umbra combines accessibility-based app control, optional privileged execution, a local Linux development environment, and background task sessions. Its execution model emphasizes explicit approval for sensitive actions, verification, resumability, and keeping the user in control.

LHIC

Open source · Computer-use runtime

Local Human Intent Controller is a local-first browser and desktop automation runtime. A deterministic, model-free Fast Path handles supported actions; an optional model-guided Slow Path proposes steps that remain subject to validation, human approval, verification, and audit trails.

02 / FEATURED PRODUCT · EDTECH
IN DEVELOPMENT
IdeaStone

The Interactive Classroom Compiler

Turn knowledge into learning you can interact with.

IdeaStone is an in-development learning platform centered on compiling source material into structured, reusable interactive classrooms. The goal is to combine adaptive tutoring, a learner model, and verifiable learning evidence while keeping high-quality courses affordable. The public product is not being presented here as a completed launch.

01 / INTERACTION

Beyond passive content

Assemble lessons from reusable explanations, simulations, exercises, checks for understanding, and learner-controlled interactions rather than one-way generated text or video alone.

02 / INTELLIGENCE

Adaptive by design

Explore structured course compilation, source-grounded quality checks, tutoring workflows, and learner-state tracking that can guide the next useful activity without obscuring what a student actually understands.

03 / ACCESS

Built for accessibility

A core design goal is inexpensive, precompiled public lessons with optional AI assistance, so interactive education can reach more learners without making every activity depend on expensive inference.

03 / RESEARCH INTERESTS

Questions I keep returning to.

My work moves between research and implementation: representations, execution, evaluation, user interaction, and the constraints that decide whether a system can work outside a demonstration.

A

Reliable Agents

How can autonomous actions across phones, desktops, and applications stay verifiable, approval-aware, and recoverable?

B

Learning Systems

How can interactive instruction adapt to evidence of understanding instead of relying on passive content or guesswork?

C

Agent Interfaces

Can structured application capabilities replace fragile UI control with efficient, deterministic agent-accessible operations?

D

Systems Engineering

How do security boundaries, constrained hardware, reproducible tests, and deployment realities shape better architectures?

05 / ABOUT

Curiosity with an engineering bias.

I am Pinyen Cheng, a student researcher and engineer at Taoyuan Municipal Dayuan International Senior High School in Taiwan. I learn best by building systems that force me to understand the underlying problem.

My interests span on-device AI agents, adaptive learning, interface representations, embedded hardware, networking, developer tooling, and practical software engineering. My long-term goal is to contribute to intelligent systems that are not only more capable, but also more efficient, interpretable, reliable, and useful in real-world settings.
